STEAMLab · Educcartito con Merge Cube

Este proyecto muestra a Educcartito en realidad aumentada sobre las caras del Merge Cube, usando el mismo archivo privado targets.mind que ya generaste con tus seis caras correctas.

No subas targets.mind a GitHub

Cómo usarlo

  • Publica estos archivos en un repositorio nuevo, por ejemplo steamlab-merge-educcartito.
  • Activa GitHub Pages en la rama main, carpeta /(root).
  • Desde tu celular, abre visor.html, selecciona tu archivo local targets.mind y activa la cámara.
  • Apunta a una cara entrenada de tu Merge Cube. Educcartito aparecerá flotando sobre ella.
